The Common Ports Reference lists the well-known TCP and UDP ports you meet in daily work - web, mail, databases, Docker, Kubernetes, message queues and more. Filter by protocol (TCP/UDP) or search by port number, service name or description. The copy button exports the current view as tab-separated values.

The dataset is embedded in the page, so every lookup is instant, offline and private.
