The Favicon Finder shows any website's icon in seconds. Enter a domain - toolsboot.com, github.com, whatever you need - and hit Find. The page pulls the favicon from Google's favicon service at five sizes, from the site's own /favicon.ico, and from DuckDuckGo's icon proxy.

Each icon can be copied as a URL or downloaded directly. Note that fetching a site's favicon requires network access to that site, but your domain is only used to build the request - no browsing data is collected.
