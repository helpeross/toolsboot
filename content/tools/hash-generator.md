The Hash Generator computes MD5, SHA-1, SHA-256 and SHA-512 digests of any text or file in real time. Tick the algorithms you need and the hashes appear on the right as you type. Upload a file and its hashes are calculated from the raw bytes - perfect for verifying downloads.

MD5 is implemented from scratch and the SHA family uses the browser's built-in Web Crypto. Everything runs locally, so files and text never leave your device.
