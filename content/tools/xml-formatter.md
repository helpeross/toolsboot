The XML Formatter pretty-prints messy XML with two-space indentation, minifies it back to a compact single line, and validates the document as it goes. Paste any XML on the left and the formatted result appears on the right immediately.

Invalid documents are flagged with the parser's error message instead of producing garbage output. The minify mode reports the size reduction percentage. Everything runs locally in your browser - no XML is ever uploaded.
