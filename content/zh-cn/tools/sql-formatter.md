SQL 格式化工具按关键字智能缩进美化 SQL 语句：SELECT 列表、JOIN、WHERE 条件与 GROUP BY 子句各自单独成行，复杂查询一目了然。工具能正确处理字符串、引号标识符以及 --、/* */ 注释。压缩模式可将查询压缩到尽可能少的行。

所有格式化均在浏览器本地完成，使用纯 JavaScript 实现。SQL 不会离开设备，适合包含敏感结构或数据的查询。
