JavaScript 格式化工具可美化或压缩 JavaScript 与 TypeScript 代码。它使用自研解析器对源码分词，能够正确识别字符串、模板串、正则字面量、行注释与块注释，格式化过程不会破坏任何代码。一键即可在美化输出与紧凑压缩版本之间切换。

本工具完全在浏览器本地运行，代码不会上传到任何服务器，可放心格式化进行中的源码、配置片段与个人脚本。
