The MIME Types Reference covers the most common file extensions and their registered media types - documents, archives, fonts, images, audio and video. Filter by category or type to search, and the list updates in real time as you type. A copy button exports the current filtered list as tab-separated values for use in configs or documentation.

The table ships with the page, so lookups work instantly with no network and no uploads.
