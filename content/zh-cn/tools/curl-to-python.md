cURL 转 Python 转换器解析 cURL 命令并改写为 Python requests 或 JavaScript fetch 代码，处理请求方法、URL、请求头、Cookie、基础认证、JSON 正文与表单数据，还会格式化 JSON 载荷便于阅读。

从浏览器 DevTools 或 API 文档复制请求后想在代码里运行，这个工具非常方便，同时支持 Python 与 fetch 两种目标。解析与转换全部在浏览器内完成。
