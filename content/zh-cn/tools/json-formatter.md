JSON 格式化器是一个纯浏览器工具，用来把杂乱的 JSON 整理成可以轻松阅读的结构。粘贴一段 API 响应、配置文件或环境变量内容，它就会以两个空格缩进美化输出，嵌套的对象和数组一目了然。

它还会在输入的同时进行校验。格式错误的 JSON——漏掉的逗号、未加引号的键或多余的尾部逗号——会给出清晰的错误提示，而不是让人困惑的崩溃。反过来，点击「压缩」可以把整个结构折叠成单行，适合存入环境变量、数据库字段或 URL 编码的请求体。

所有处理都在本地用纯 JavaScript 完成，你的数据不会离开设备。这里没有「粘贴即上传」的陷阱——检查凭据或内部接口时这一点尤为重要。复制结果继续干活即可，无需登录、没有限制、不留指纹。
