JSON 转 Go 结构体生成器可一键从 JSON 示例生成类型化的 Go 结构体。嵌套对象会生成嵌套结构体，数组会推导元素类型生成切片，每个字段都会附带匹配的 json tag；数字会根据取值自动推断为 int 或 float64。

粘贴一段 API 返回的 JSON，即可把生成的结构体直接复制到你的 Go 项目中。所有转换均在本地完成——JSON 示例不会离开你的浏览器。
