JSON 转 C# 转换器从 JSON 数据生成 C# 实体类：每个对象生成一个类、属性自动转 PascalCase、数字按类型映射为 long 或 double，嵌套对象与对象数组生成独立类。

输出附带 System 与 System.Collections.Generic 命名空间引用，可直接粘贴进项目，是快速构建 DTO 的好帮手。全部转换在浏览器本地完成，不上传任何数据。
