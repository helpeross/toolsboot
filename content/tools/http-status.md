The HTTP Status Codes reference bundles every common status code from 100 Continue to 511 Network Authentication Required. Search by number or phrase - try 404 or "teapot" - or filter by class with the 1xx through 5xx buttons.

Each entry shows the code, its official phrase, a plain-English description and the category, with colors matching the status class. The whole database ships inside the page, so it works offline with zero requests.
