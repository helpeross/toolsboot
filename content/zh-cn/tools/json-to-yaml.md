JSON 转 YAML 转换器在 JSON 与 YAML 两种格式之间双向转换。粘贴 JSON 即可得到缩进规范、注释友好的 YAML，适合配置文件、CI 流水线或 Kubernetes 清单；反过来粘贴 YAML 也能还原成标准 JSON。

解析器对常见错误给出明确提示，如缩进错误、意外内容、混合块样式等，方便快速定位问题。转换结果支持复制与下载。

所有转换均在浏览器本地完成，数据不会上传。
