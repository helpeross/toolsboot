The Morse Code Translator converts plain text to Morse code and back in real time. Letters, digits and common punctuation are supported, and the classic convention is followed: characters are separated by a single space and words by three spaces (or a slash).

Switch between text-to-Morse and Morse-to-text with one click. The translation updates live as you type and runs entirely in your browser - nothing is uploaded. Use it for learning Morse, encoding secret notes, or just for fun.
