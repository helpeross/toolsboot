URL 参数转 JSON 工具可把任意查询字符串——或包含查询串的完整 URL——转换为可读的 JSON 对象。重复参数会合并为数组，加号与百分号编码会被正确解码，嵌套结构同样支持。

切换到「JSON → URL」模式，即可把 JSON 对象序列化回编码后的查询字符串。转换实时在浏览器中完成，因此即使 URL 中含有敏感令牌，也可以放心查看而不会发送到任何地方。
