JSON 转 TypeScript 转换器把任意 JSON 载荷转换为可直接使用的 TypeScript 接口：嵌套对象生成独立接口、数组推断元素类型、基础类型映射为 string、number 或 boolean。左侧粘贴 JSON，右侧实时生成接口。

拿到 API 响应或配置文件后想快速得到类型定义时非常省时。输出为无依赖的标准 TypeScript。全部在浏览器本地处理。
