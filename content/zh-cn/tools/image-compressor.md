图片压缩工具直接在浏览器中缩小 JPG、PNG 与 WEBP 图片的体积。拖入或点击选择图片后，可调节质量、最大宽度与输出格式；实时预览会同时显示压缩结果、原始大小、新大小与节省百分比。点击下载按钮即可保存优化后的图片。

压缩通过 Canvas API 在设备本地完成，图片不会上传，即使是敏感图片也能放心处理。
