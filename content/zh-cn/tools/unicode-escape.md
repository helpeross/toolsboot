Unicode 转义工具将文本转换为 \uXXXX 转义序列，这是 JSON 负载、Java 与 JavaScript 源码等场景中编码非 ASCII 字符的常用格式。emoji 等超出基本平面的字符会以代理对形式输出，并可按原样无损还原。解码时也支持 \u{...} 与 \xXX 格式。

转换完全在浏览器本地完成，文本不会离开设备。
