The Placeholder Image Generator creates placeholder images with your exact width, height, background color, foreground color and text. The preview updates live, and the same image can be downloaded as a crisp PNG or an infinitely scalable SVG.

Pick colors with the color inputs or type hex values directly. The copy button grabs a data URL of the image for embedding in prototypes. Images are generated entirely in your browser - nothing is uploaded.
