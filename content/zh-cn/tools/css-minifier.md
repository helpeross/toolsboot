CSS 压缩器去除样式表中的空白、换行与注释，产出更小、加载更快的样式文件，适合生产环境部署。左侧输入原始 CSS 或点击按钮上传 .css 文件，压缩结果即时显示在右侧。

反向操作同样支持：点击「格式化」可以把压缩后的 CSS 还原成缩进清晰、易读的结构，方便调试与维护。输出区支持复制与下载压缩后的文件。

所有处理均在浏览器本地完成，样式内容不会上传。
